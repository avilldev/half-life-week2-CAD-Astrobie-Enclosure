# Astrobie Enclosure
<img width="2065" height="1006" alt="image" src="https://github.com/user-attachments/assets/8c38c7d0-65c0-469c-bb75-da632e73fccb" />

The enclosure designed for my Week 1 Hack Club Halflife PCB project, [Astrobie](https://github.com/avilldev/half-life-week1-PCB-Astrobie).

## Features
* **Screwless Assembly:** The lid and base snap together using an internal lip with a 0.2mm clearance.

<img width="403.25" height="203.75" alt="image" src="https://github.com/user-attachments/assets/263f9129-faf4-433e-9f7e-fea039f3bf02" />


* **Ergonomic Design:** Rounded edges for a smooth finish.
* **Component Cutouts:** Cutouts for the USB-C port, the OLED display, pushbuttons, and components that stick out due to the size.

<img width="234.5" height="159" alt="image" src="https://github.com/user-attachments/assets/2082b354-ef9e-4f6c-8a9c-16192e3107f3" />
<img width="383.4375" height="159.375" alt="image" src="https://github.com/user-attachments/assets/43461b8e-fa11-4061-876c-6d116492be96" />


* **Pixel Art:** Decorated on the front with the pet alien pixel-art that is part of the Astrobie firmware.
* **PCB Support:** Pillars supporting the PCB board from the bottom.

<img width="252.125" height="130.75" alt="image" src="https://github.com/user-attachments/assets/039dac4c-97e3-4f86-bd63-f90d072ab7fe" />


## Printing Specifications
* **Material:** PLA (Galaxy Blue color, or similar)
* **Infill:** 15%
* **Wall Count:** 3 Walls
* **Supports:** Supports are necessary for both the base and the lid.
